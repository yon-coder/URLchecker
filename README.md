## 📋 Requisitos do sistema

Antes de executar o projeto, certifique-se de ter:

* **Python 3.8 ou superior**
* **Conexão com a internet**, necessária para consultar os feeds de ameaças
* **Sistema operacional:** Windows, Linux ou macOS

O projeto utiliza apenas bibliotecas nativas do Python, portanto **não é necessário instalar dependências externas**.

---

## 🚀 Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/yon-coder/URLchecker.git
```

### 2. Acesse a pasta do projeto

```bash
cd URLchecker
```

### 3. Execute o programa

No Windows:

```bash
python main.py
```

No Linux/macOS:

```bash
python3 main.py
```

### 4. Uso

Após iniciar, o programa fará o download das bases de ameaças automaticamente.

Em seguida, informe a URL que deseja verificar:

```text
🔗 Cole o link aqui:
```

Para encerrar o programa, digite:

```text
sair
```
